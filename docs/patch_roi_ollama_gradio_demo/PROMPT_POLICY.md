# Prompt Policy

## 目的

`src/patch_roi_report_prompt.py` 建立固定 system prompt 與結構化 user prompt。Ollama 只負責將模型已產生的結果改寫成繁體中文研究說明，不得看圖、重算機率、重新分類或更改預測。

## 必要輸出結構

1. 一、模型結果摘要
2. 二、類別一般說明
3. 三、機率與限制
4. 四、研究用途聲明

固定聲明：

`本結果僅供研究與系統展示，不是臨床診斷，不能取代合格醫療專業人員的判讀。`

## 禁止內容

- 臨床診斷、鑑別診斷、治療、用藥或醫療建議
- 未提供的患者資訊、病史、症狀、影像位置、嚴重度或預後
- 完整胸腔 X 光、BBox 或偵測結果的虛構描述
- No finding、Normal、Background 或第六類
- 將 Softmax confidence 描述為診斷機率、盛行率或臨床風險

## 驗證與重試

回應必須包含四個標題、預測類別中英文名稱與固定聲明，且不得出現禁止類別。第一次回應不合規時重試一次；仍失敗則顯示本機 Ollama 錯誤，不使用替代 LLM。

日誌只保存每次實際 prompt 的 SHA256，不保存完整 prompt、回應、圖片、base64 或患者文字。
