摘要

本研究比較 ImageNet baseline、RAD-DINO CLS 全域特徵蒸餾與 RAD-DINO 7 x 7 Patch 局部特徵蒸餾，探討醫學影像基礎模型知識是否能改善輕量 ConvNeXt-Tiny 的五類病灶 ROI 分類。

Patch Phase 1 最佳 normalized MSE 為 0.0002644、cosine similarity 為 0.8985，證明局部表徵對齊成功。Test 上三模型整體接近：Baseline macro F1 最高，Patch loss 最低且 weighted F1 最高，CLS macro AUROC 略高。Patch 提升 Pleural thickening F1，卻降低 Pleural effusion F1。以 59 個 source-image clusters 進行 10,000 次 paired bootstrap，所有主要模型差值的 95% CI 均跨越 0。

結論：Patch feature alignment 成功，且造成類別特異性的決策改變；目前沒有足夠證據支持其對整體分類具有穩定、全面、統計顯著的優勢。

1. 研究背景與動機

胸腔 X 光病灶常具有低對比、小尺度與類別間外觀相似等特性。RAD-DINO 提供放射影像領域表徵，但運算成本較高；ConvNeXt-Tiny 較適合作為可部署學生模型。傳統 CLS 蒸餾將整張 ROI 壓縮為單一向量，本研究進一步保留 patch 空間資訊，希望對局部病灶更有幫助。

2. 研究問題

  1. RAD-DINO CLS 特徵能否有效蒸餾至 ConvNeXt-Tiny？
  2. Patch-level 蒸餾能否優於 ImageNet baseline 與 CLS 蒸餾？
  3. 局部蒸餾是否改善特定病灶，尤其 Pleural thickening？
  4. 模型點估計差異在 source-image clustered bootstrap 後是否仍成立？

3. 研究貢獻

  • 建立 full image、BBox、原始 ROI、224 x 224 ROI 的可追溯資料主線。
  • 建立 [4725,768] CLS cache 與 [4725,768,7,7] Patch cache。
  • 完成相同 grouped split 與 Phase 2 設定下的三模型公平比較。
  • 以 source cluster 而非獨立 ROI 進行主要統計推論。
  • 辨識 Pleural thickening 與 Pleural effusion 的類別 trade-off。

5. ROI 前處理與平衡

原始像素 BBox 以 margin_ratio = 0 裁切，再保持比例縮放、置中並以像素值 0 黑色 padding 補成 224 x 224。沒有直接拉伸、沒有 mean/std normalization。平衡資料包含 4,256 張正式原始 ROI 與 469 張 brightness augmentation，五類各 945，共 4,725 張。

7. 模型架構

三模型均採 ConvNeXt-Tiny backbone，接 global average pooling、768 維 feature、dropout 0.2 與 Linear(768,5)。唯一允許的核心差異是 backbone initialization：ImageNet、CLS distilled 或 Patch distilled。

8. RAD-DINO CLS 蒸餾

教師使用官方 microsoft/rad-dino 與 AutoImageProcessor，設定為 frozen、eval、inference mode。快取形狀 [4725,768]、float32 CPU，NaN、Inf、zero norm 都是 0。學生與教師做 L2 normalization 後最小化 normalized MSE；最佳 epoch 30 的 MSE 為 0.0003958、cosine 為 0.8480。

9. RAD-DINO Patch 蒸餾

RAD-DINO 對 518 x 518 輸入使用 14 x 14 pixel patches，產生 37 x 37、共 1,369 個 patch tokens。移除 special token 後重排為 [B,768,37,37]，以 adaptive average pooling 轉為 [B,768,7,7]，對齊 ConvNeXt-Tiny 最終 feature map。

完整 cache 為 [4725,768,7,7]，約 711 MB；NaN、Inf、zero spatial norm 都是 0。Epoch 84 的 normalized MSE 為 0.0002644、cosine 為 0.8985。

10. Phase 2 公平性設計

三模型共用 split、preprocessing、augmentation、seed、optimizer、learning rate、batch、early stopping、checkpoint selection 與 test-once 程序。公平性稽核 57 項通過，非允許差異為 0；每個模型各 454 筆 predictions，配對鍵完整。

LayerNorm 限制： Baseline final LayerNorm 來自 ImageNet；CLS 來自 CLS Phase 1 checkpoint；Patch Phase 1 匯出未包含 final LayerNorm，因此 Patch Phase 2 使用 torchvision 預設初始化。這是 CLS/Patch 比較的潛在混淆因子。

13. Confusion Matrix 與 Class 2/4 Trade-off

Patch 將 Pleural thickening 正確數由 51 提高至 65，class 2 -> 4 由 40 降至 22；Pleural effusion 正確數由 59 降至 42，class 4 -> 2 由 20 增至 37。

14. 統計分析

主要分析以 59 個 source-image clusters 做 10,000 次 paired bootstrap，固定 seed 42，比較三組模型配對的 accuracy、macro F1、weighted F1 與 macro AUROC。12 個 95% confidence intervals 全部跨 0。

ROI-level exact McNemar p 值為 CLS vs Baseline 0.770867、Patch vs Baseline 1.000000、Patch vs CLS 0.765992；Holm-adjusted p 全部為 1.0。McNemar 只作補充，主要推論採 clustered bootstrap。

16. 主要發現

  1. CLS 與 Patch 特徵都能有效轉移，Patch alignment 更接近教師。
  2. 成功對齊 feature 不保證下游分類全面提升。
  3. 三模型整體指標接近，統計證據不足。
  4. Patch 的主要影響是 class 2/4 決策邊界重新分配。
  5. Patch Phase 2 較早達到最佳 checkpoint，但前置蒸餾成本較高。

17. 研究限制

  • Test 只有 59 個 source-image clusters。
  • Phase 1 使用全部 4,725 張未標籤 ROI，屬 transductive setting。
  • Patch checkpoint 未包含 final LayerNorm。
  • 只有 seed 42，未估計訓練隨機變異。
  • 單一資料集，尚無外部驗證。
  • ROI classification 不等同 full-image detection 或臨床效益。

19-20. 結論與可重現性稽核

RAD-DINO Patch-level feature distillation 成功讓 ConvNeXt-Tiny 對齊教師局部表徵，Pleural thickening F1 從 0.5455 提高到 0.6019，但 Pleural effusion 降到 0.5793。三模型整體指標接近，所有 source-cluster bootstrap 95% CI 跨 0，因此不能宣稱 Patch 蒸餾具穩定全面優勢。
